Data Analyst

Reference Number: FT0001

The Data Analyst supports Finova Technologies by analysing financial and customer data to help the company make better business decisions.

Salary: $75,000 - $90,000 per year

Reports To: Senior Data Manager

Key Responsibilities

  1. Analyse financial and customer data.
  2. Create reports and dashboards.
  3. Identify trends and patterns in business data.
  4. Present findings to managers and team members.

Essential Requirements

  • Knowledge of SQL and Excel.
  • Strong analytical and problem-solving skills.
  • Good written and verbal communication skills.
  • Ability to work effectively in a team.

Preferable Requirements

  • Experience with Power BI or Tableau.
  • Knowledge of financial technology services.
  • Basic knowledge of Python.

Software Developer

Reference Number: FT0002

The Software Developer designs, develops and maintains secure digital applications used by Finova Technologies customers and employees.

Salary: $80,000 - $100,000 per year

Reports To: Software Development Manager

Key Responsibilities

  1. Develop and maintain financial applications.
  2. Test and debug software systems.
  3. Work with team members to develop new features.
  4. Maintain secure and reliable application code.

Essential Requirements

  • Knowledge of programming languages such as JavaScript, Java or C#.
  • Good problem-solving skills.
  • Understanding of software development principles.
  • Ability to work effectively in a development team.

Preferable Requirements

  • Experience with web application development.
  • Knowledge of Git and GitHub.
  • Understanding of financial technology systems.

Cybersecurity Analyst

Reference Number: FT0003

The Cybersecurity Analyst helps protect Finova Technologies' systems, customer information and financial data from security threats.

Salary: $85,000 - $105,000 per year

Reports To: Cybersecurity Manager

Key Responsibilities

  1. Monitor systems for possible security threats.
  2. Identify and respond to security incidents.
  3. Protect customer and financial information.
  4. Assist with security reviews and risk assessments.

Essential Requirements

  • Knowledge of cybersecurity principles.
  • Understanding of network security.
  • Strong attention to detail.
  • Good analytical and problem-solving skills.

Preferable Requirements

  • Knowledge of cloud security.
  • Experience using security monitoring tools.
  • Understanding of financial data security.
